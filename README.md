# Expense Manager

A simple Python program to manage daily expenses.

## Features

* Add an expense
* Add expense amount and category
* View all expenses
* Calculate total spending
* Exit the program

## Concepts Used

* Lists
* Dictionaries
* Loops
* Conditional statements
* User input
* `sum()`
* f-strings

## How to Run

1. Make sure Python is installed.
2. Run the Python file.
3. Choose an option from the menu.
4. Add and view expenses as needed.

## Example

```text
1. Add Expense
2. View Expenses
3. Total Spending
4. Exit
```

The program stores each expense with its name, amount, and category.
